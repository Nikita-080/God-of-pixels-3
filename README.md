# CORE Update — v2.0.0

<img src="promo/core_preview_crop_3.gif">

> **A new foundation for God of Pixels 3.**

The **CORE Update** is one of the biggest technical change in the history of God of Pixels 3.

The original custom 2D rendering system has been replaced with a new **OpenGL-based 3D renderer**.

This is more than a visual upgrade. God of Pixels 3 is now a true 3D application, with a completely new rendering foundation that opens the way for future features and more advanced planetary simulation.

Alongside the new renderer, CORE introduces many new features and systems for creating and exploring planets.

## What's new

### New 3D Renderer

The original 2D renderer has been replaced by a new OpenGL-based 3D rendering system.

You can zoom and rotate your project.

# About

It's a simple constructor or graphic editor, or simulation or something else.

Here you can create your own planet. Configure ocean level (or make it desert), set comfortable temperature value (or begin forever winter), create plants (or make the world lifeless). It's only small part of opportunities.

Create your own world among infinity space.

It begun some years ago as a small school project, and now i want to share it. I saw as numbers and algorithms borns small worlds just in front of eyes. I  just wanted to create something beautiful.
